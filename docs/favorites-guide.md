# 自动测试与糖果结果 · 1.0.5

本文对应 GitHub 正式版本 1.0.5；升级沿用已有模型、参数、计划和历史。

## 页面与模型

“收藏”标签改为“自动测试”，进入默认糖果视图。该页只有糖果、动画长廊两种视图，按计划运行；手动测试分别使用鹈鹕动画、模型指纹、糖果测试三个独立标签。历史记录保留原来的所有类型。

从任一测试页选供应商和模型后，点击“加入自动测试”，保存当前思考档位、输出上限、生成超时和动画提示词；也可在自动测试页“添加模型”。按包含供应商的稳定模型 ID 去重，模型数量不设上限，每页显示 24 个模型。

每个模型卡片右上角的设置按钮只编辑当前模型、当前测试类型。下面的计划行是纯文本：无计划显示“暂无计划”，设置后显示时刻或间隔。糖果与动画各有一份计划、独立开关；同模型同类型不能创建重复计划。参数从计划侧栏的“模型参数”或“管理模型 → 编辑”进入。移除模型会删除它的未来计划，历史记录继续保留。

## 日程与数量

支持指定时刻、固定间隔；星期支持每天、工作日、周末和自选星期。工作日仅为周一至五，周末仅为周六日，不包含节假日调休。时区默认取页面所在系统的 IANA 时区，也可修改。

每模型、每测试类型、每计划日最多 **24 次**；糖果 24 次和动画 24 次分别计算。指定时刻排序去重后计数。间隔开始包含、结束排除，次数是窗口分钟数除以间隔后向上取整。全天每 60 分钟一次是 24 次；09:00–18:00 每 30 分钟是 18 次，每 20 分钟是 27 次，界面和后端均拒绝。保存前显示实际次数与超限建议。

结束早于开始为跨午夜，凌晨窗口仍归开始日。DST 回拨的重复钟点仅在第一次对应的实际分钟触发；第一次已错过时，第二次不会补跑。DST 跳过的时刻标记跳过。卡片显示当前计划日。修改计划后，自动查找当前模型、当前测试类型在各格原定日期和时刻的已有结果；指定时刻与固定间隔互换、时刻删掉再加回、删除后重建计划均可复用。单纯暂停/启用保留当天时间格和对应结果。

例如今日 09:00 已有结果，把指定时刻改为 09:00–12:00、每 60 分钟一次后，09:00 沿用原结果，10:00、11:00 按新计划显示。匹配精确到分钟，使用原定执行时间，排队后延迟开始不会挪到另一个格子。跨午夜按各格的实际日期匹配；相同钟点在不同时区代表不同的执行时刻时不会混用。

同一时刻有多条记录时，优先显示已完成的结果；多个完成结果取较新的一条，不偏向答案是否为 21。没有完成结果时，优先显示正在生成、有实际执行记录、排队、未执行的取消记录。复用原记录的答案、Token、动画文件和详情，保留原模型参数及历史批次，不新增模型请求。旧计划仍在生成的任务会继续更新；完成或清理后立即刷新关联。已经删除、超过保留期或缺少可靠原定时间的记录不能跨计划找回；手动测试不填入自动计划。

保存期间对应表单的输入、编辑、移除和提交控件暂时锁定，避免保存响应覆盖后续编辑；仍可关闭面板。管理模型中的编辑、移除和并行数修改一次保存，任一项无效或写入失败时全部保留原值；计划与该模型的参数也一起保存，失败后解除锁定，草稿可继续修改或重试。切换执行方式时，只提交当前方式的参数；无效时区在保存前提示。糖果卡随结果更新保留按钮和焦点，动画开关保留长廊的滚动位置。

新计划默认暂停；开启后按未来时刻执行，保存不立即追加一次测试。后台每 5 秒检查分钟边界，插件服务必须运行；休眠、退出或崩溃错过的时刻不补跑。同模型同类型的不同计划时刻分别创建任务：上一轮未完成时，有并行额度则同时运行，否则排队；各时刻独立保存结果。同一时刻重复触发仍只执行一次。暂停/删除/更改计划或超过结束时间窗会取消尚未开始的请求，已发出的继续完成，可在详情/历史中取消。旧版本已记录的“上一轮未结束，已跳过”仍保留，不在升级时补发请求。

自动请求并行数默认 3，在“管理模型”中直接展开显示，无人为最大值，**0 表示不设插件并行上限**。保存后立即作用于排队任务，重启仍保留零值。它只控制同时在途的请求数，各模型依照自己的时刻运行。

## 糖果卡与动画长廊

糖果卡以模型、供应商两行显示名称，成功率为答案 21 的次数 ÷ 已有明确数值答案的次数。21 绿色，其他明确数值红色。排队与生成中不算失败，也不算未判定；没有最终答案时明确显示“生成中”或“排队中”。有已完成结果时继续保留成功率并显示当前运行状态。

同类糖果卡的外框与内部各行保持对齐。无计划、暂停或尚无用量时预留原位置；动画长廊也为无结果的时段保留与结果卡相同的高度。

一格对应一个计划时刻，实际计划 3 次就显示 3 格。未来待运行、暂停、错过、跳过、请求失败、待复核有不同文字/符号。点击已执行格子查看原始回答，运行中的详情完成后同步答案与复制内容。原始模型参数保存在每条运行记录中，后续参数修改不会改写以前的成绩。

时间条以每行 24 格对齐，较少时段沿用相同格宽并靠右，历史超过 24 个时段时另起一行。虚线表示已暂停、已错过或已跳过，具体状态见悬停文字。当前时段用顶部标记，键盘焦点用底部标记，历史中选中的时段有蓝色轮廓。可访问标签与悬停文字均包含时间和状态。

记录格支持左右方向键及 Home/End。打开详情后可查看回答、思考和用量；长内容和输入框显示细滚动条，尚无回答时不能复制。关闭侧栏返回原操作入口，侧栏内切换模型参数时从顶部显示。

动画每模型一行，当天所有时间点从新到旧横向排列。打开、刷新或从其他测试页返回时，默认定位当前时间之前最近的计划时刻；该时刻无论成功、失败、取消、中断、截断、排队或没有结果，都显示自身状态，不回退到更早的成功动画。到达新时刻或该时刻出现任务时自动跟随。仍可拖动底部滚动条或键盘滚动，普通用量更新及暂停/启用计划保留手动位置。未到时间的卡显示占位，可向左查看；当天还没有已到达时刻时，定位第一个即将到来的时刻。无计划时预留时间栏和结果高度。已完成卡复用重播、浏览器打开、详情、用量和隔离预览。隐藏/离屏 iframe 卸载，滚动回来继续显示同一已保存文件。切换测试类型或供应商筛选时回到列表顶部。

三种独立测试、历史、自动测试共用“思考 / 输出”行。真实 Token 优先，尚未返回用量时显示已收到字符数，未知为 —，明确零为 0。输出 Token 是接口原值，可能包含思考，不可两项相加。独立指纹卡直接显示三次采样数量，部分汇总用量带 ≥。

## 输出上限、生成超时与升级

新测试和新添加模型默认 **64000 Token**。填写 **0 = 不设输出上限**：插件省略 max_tokens/max_output_tokens，由模型和网关决定实际默认限制。响应大小保护继续生效。指纹选到原生 Messages 且上限为 0 时，预先使用 Magpie Chat 兼容接口；记录展示实际接口，无法兼容的供应商可能返回接口错误，不自动重试。

生成超时默认 **600 秒**，在计划侧栏“模型参数”或“管理模型 → 编辑”中修改，单位秒；**0 = 不设插件侧超时**。每次自动运行保存当时的超时，后续修改不改写历史；原条件复测继承历史值。同条件趋势会区分不同超时。旧模型和旧历史没有此字段时按 600 秒处理，默认条件仍沿用原有统计。供应商或网关自身的超时仍可能更短。

旧模型已保存的自定义数值保留（包括旧 32000），不会被强制重置。升级时在 .favorites 下保存 state-v1-backup.json；如文件已存在则用唯一后缀另存。旧共享计划拆成每模型/类型独立计划；移除指纹自动项目。重叠或超限的旧计划暂停并标注需要重新设置，原配置完整保存在备份中。旧总开关关闭时，迁移出的各计划保持暂停。

结果与生成文件默认保留 7 天；自动模型和计划长期保留。清理历史不会删除模型或日程。自动结果按本地日期和测试类型查看，同日同类且原定执行分钟一致的模型共用一个历史条目；缺少可靠原定时间的旧记录不强行合并。历史糖果卡只显示所点模型在该时段的结果，再点同一条收起。历史动画最新在左、最早在右，点击「最新」「最早」会同步直达当前所选每日批次各模型行的两端，不跨日期；到头时对应按钮不可用。自动测试页自身仍保留较早、当前和较新时段导航。导出和单批删除仍涵盖整个条目。

收藏配置损坏时自动测试停用，页面显示恢复说明；历史与手动测试仍可使用。收藏和计划暂时只读，原配置文件保留，恢复配置后重新开启插件。
