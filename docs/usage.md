# 模型实验室使用说明 · 1.0.4

## 模型与参数

首次打开时使用宿主的明暗模式。页面内手动切换主题后，刷新保留所选主题及当前视图。

先选择供应商，再搜索、勾选模型；默认“全部供应商”可跨供应商比较。切换供应商不会清空已经勾选的模型，“清空”一次移除全部选择。思考档位只展示模型目录支持的选项。

手动测试的提示词和高级设置默认折叠。动画每批默认并行 2 个请求，指纹、糖果默认 3 个；不同测试页分别保留编辑值。模型数量没有插件限制，并行数接受非负整数，**0 表示不设插件并行上限**。指纹并行按实际采样请求计数，每模型共 3 个样本。

最大输出默认 **64000 Token**。**0 表示不设插件输出上限**：请求中省略输出上限参数，由供应商和网关决定实际限制。它不保证无限输出，也不是费用硬限额。新测试使用默认值；已经保存的自动模型参数保持原值。

指纹选择原生 Messages 接口且上限为 0 时，会预先使用 Magpie 的 Chat 兼容接口，因为原生 Messages 要求正数 `max_tokens`。记录会注明实际接口；不兼容时返回错误，不自动切换重试。

## 结果与用量

三种手动测试共用模型名、供应商、思考／输出用量的布局。排队、生成中、完成、停止、失败和截断分别显示。取消本批次会终止正在执行及排队的请求，已收到的内容继续保留。

本批结果下方按相同模型顺序显示最近 **5 个已结束的历史批次**。结果区最底部的「前往历史记录」会打开历史页，自动筛选当前测试类型和「手动测试」，从最新记录开始查看；历史不足 5 批时显示已有批次。

接口返回 Token 时直接显示；尚无用量时显示已收到字符数。`—` 表示未知，`0` 表示接口明确报告零。输出 Token 可能已经包含思考 Token，两项不能直接相加。指纹部分样本已返回的用量用 `≥` 表示部分汇总。

### 鹈鹕动画

默认提示词让模型生成鹈鹕骑自行车的 HTML 动画，也可以修改。结果等比缩放到小卡片，长模型名不改变卡片高度。「查看详情」打开右侧抽屉，可切换动画预览、HTML 源码与原始输出，也可停止／播放预览。

重播与浏览器打开读取已保存结果，不重复调用模型。预览链接可跨服务重启使用，删除对应结果后失效。离屏或切页后的动画会卸载预览，返回时重新显示保存文件。

预览允许内联脚本、样式、SVG、Canvas 和 data 图片，限制网络、表单、嵌套框架与对象。模型生成了外部资源依赖或自身布局错误时，动画可能不完整；原始 HTML 保存在结果目录中。浏览器打开按钮使用相同预览限制。

### 模型指纹

同批模型使用相同的 3 个随机数字挑战，每个样本独立请求。卡片直接展示采样数量、进度和首候选，省略的候选名称和参考模型家族可悬停查看全文；详情中可看原始采样、排名、路由与参考库哈希。也可以从 Magpie 供应商菜单的“检测指纹”进入并预选该供应商。

首次有效检测时下载参考库，之后使用本地快照；点击“更新参考库”才主动更新。更新失败继续保留旧缓存。参考数据默认来自 `lm.ikale.io` 或 `cdn.jsdmirror.com`，不上传你的测试记录；模型请求仍发送到所选供应商。

高级设置可选择严格模式、接口、服务档位和固定供应商账号。“固定供应商账号”用于供应商拥有多个登录账号、需要指定其中一个时；关闭时由 Magpie 自动分配。账号标识只在使用该选项时需要填写。

非严格模式可以对有效的部分样本排名，但不完整证据不显示概率；严格模式要求 3 个完整且未截断的样本。明确路由不一致时不评分。匹配结果只反映参考库覆盖范围内的证据，不能当作模型身份鉴定。

### 糖果测试

使用固定题目提取最终数值答案。21 为绿色，其他明确数值为红色；请求失败、截断、无法明确提取答案时单独标明，避免混为答错。详情保留完整回答与思考。

自动成功率的分母仅包含已有明确数值答案的记录。生成中、排队和待复核不计为失败；数值命中并不证明推理过程正确。

### 原因说明与近期趋势

异常卡片和详情会区分生成超时、请求限流、认证／权限错误、响应中断、保存失败、输出截断、无效输出、指纹无法评分及糖果答案不匹配等原因，并给出相应建议。无法确定具体原因时保留「请求失败」，原始错误仍可查看。结果读取失败应先重试读取；动画当前预览的运行错误与模型生成状态分别显示，查看源码或暂停预览不会清掉刚观察到的错误。

三种结果详情均提供默认收起的「同模型近期趋势」。只统计当前保留历史中最近 **20 条同模型、同题面、同完整参数的已结束记录**，不包含进行中和已取消的记录。糖果显示答案命中率，分母为可明确判定的答案，包含不匹配答案；动画显示生成完成率，完成不代表预览运行正确；指纹显示可评分率及最近候选分布，只有同一组原题与同一参考库的记录才会合并。

耗时和总 Token 使用可判定／可评分／已生成结果的中位数，标为部分汇总的总 Token 不参与精确中位数；少于 3 条可用结果时显示样本不足。异常数量包括已明确判定为不匹配的糖果答案，因此与可判定数量并非互斥。展开后可滚动查看记录表；色条从早到晚排列，点击跳到原历史记录并自动筛选其测试类型与来源。旧记录原条件不完整时暂不汇总趋势。

## 自动测试

从手动测试页选好模型后可“加入自动测试”，或在自动测试页“添加模型”。每模型的糖果和动画各有独立计划与开关，共用该模型保存的思考档位和输出上限。自动页不含指纹测试。自动请求共用可配置并行额度，默认 3；管理模型页直接显示并行输入，0 表示不设插件并行上限。

支持指定时刻、固定间隔、工作日、周末、自选星期和时区。新计划默认暂停，开启后从未来时刻开始执行；插件服务需要保持运行。每模型、每种测试、每计划日最多 24 次。

糖果卡一格对应一个计划时刻，24 格正好铺满一行；点击已执行的格子可看详情。动画按模型一行，当天各时刻从新到旧横向排列。默认把当前时间之前最近的计划时刻放在可见区域左侧，成功、失败、取消、中断、截断、排队和空结果均按同一规则选择，不会跳回更早的成功结果。到达新时刻或该时刻出现任务时自动跟随；可手动滚动，普通用量与计划状态更新保留位置。刷新页面或从其他测试页返回长廊时重新定位。当天尚无已到达时刻时，显示第一个即将到来的时刻。

同类卡片保持等高，缺少结果或用量时预留对应位置。详情中的长内容显示细滚动条，头部与关闭按钮保持可见；JSON 和参数输入框也可单独滚动。

修改计划时，按模型、测试类型和原定执行分钟复用已有记录；排队延迟不改变匹配时刻，指定时刻与固定间隔互换也可复用。同一时刻已有任务或结果时不新增模型请求。详细的时区、跨午夜、暂停、清理和升级规则见 [自动测试说明](favorites-guide.md)。

## 历史与清理

手动测试按提交批次记录；自动测试按本地日期和类型分组，同日同类且原定时间点一致的模型并排显示。可按类型、来源筛选，再次点所选条目可收起预览。每批提供导出操作，在批量清理面板打开时可删除单批；活动批次需结束后才能整批删除。

历史动画每日长廊每个模型一行，最新在左、最早在右。「最新」「最早」会一次同步跳到当前所选每日批次各模型行的最左或最右，不跨日期；到达对应端点后按钮禁用。自动测试页仍保留较早、当前和较新时段的原有导航。

三种手动测试的本批次、最近五个历史批次，以及历史页的手动批次，在标题行右侧提供「原条件复测」。历史批次标题与按钮保持对齐，窄窗口中的时间和数量显示在下一行。

「原条件复测」可从同一手动批次中选择多条记录，也可在单条详情中点击「复测此条」。自动历史需先选模型和时刻，再从该条详情复测，一次仅运行一条。核对页的参数只读，支持选择全部可复测记录、仅选异常，或按当前出现的超时、限流、截断、答案不匹配等原因选择；失败、中断、截断、无效输出、糖果待复核及明确答错均属于异常。只有该类别中具备完整原条件的记录会被选中，不能复测的记录保留禁用说明。默认排除已取消记录，正在测试的记录不可复测；选择分类本身不会发送生成请求。

复测使用保存的原模型、题面、思考档位、输出上限和并行数；指纹另保留原三组挑战、实际接口、采样设置、固定账号及参考库快照。缺少原条件、原模型或原参考库时会禁用并显示原因。提交后创建新的手动批次，保留原记录、自动计划和侧栏未提交的参数草稿；来源说明可跳回原历史记录并定位原模型和原时刻，原记录清理后会显示提示。

点击“批量清理”展开选项，按钮变为“关闭”。关闭只收起面板并保留输入。可清除全部，或按本地 `YYYY-MM-DD HH:mm` 清理指定时刻之前的结果；批量清理会保留正在运行与排队的任务。

结果默认保留 7×24 小时，以结束时间计算，没有结束时间的旧记录使用创建时间。服务启动及运行期间每小时检查一次；达到清理条件的结果和生成文件一起删除。自动模型、计划和指纹参考库不随结果清理。

历史列表常驻摘要，原始回答、思考、HTML 和采样正文在打开详情、预览或导出时按需读取。损坏记录单独跳过，原文件保留供恢复，不会阻断健康历史列表。

批次 JSON 包含模型、时间、参数、原始输出与已有检测结果，用于留档和离线分析。点击历史批次的导出图标，在右侧抽屉查看内容，选择「复制 JSON」或「下载 JSON」。「下载 JSON」打开系统另存为窗口，选择文件夹和文件名，成功后显示实际保存路径；取消不生成文件，失败后可重试。保存窗口未关闭时不能重复打开另一个；批次仍在运行时需等待结束后保存。读取失败可重试；关闭抽屉后列表仍停在原处。当前没有导入恢复功能，导出也不会搬移引用的本机文件。分享前请检查其中的个人内容。

单次批次导出与 JSON 保存使用 **16 MiB 预算**，按保存记录大小预检并核验实际序列化内容；同时只处理一个批次导出。超限会明确提示，历史详情和原始文件仍保留。大型批次可从「保存位置」取得每条记录的原始文件；后续测试可减少单批模型数量，分批留档。

## 保存位置与升级

默认保存于 Magpie 配置目录的 `magpie-pelican-bench/runs`，每条记录独立保存 `run.json`、回复、可用的思考文本、HTML 或采样文件。“保存位置”直接打开文件夹，旁边箭头可展开完整路径。

升级继续使用原来的插件 ID 和数据目录。替换文件后在 Magpie 中关闭再开启插件，重新打开“模型实验室”，在高级设置底部确认 **1.0.4**。已有计划、已保存参数和历史不会因版本更新而重置。

收藏配置损坏时，服务保留原配置文件并停用自动调度；页面显示恢复说明，收藏和计划暂时只读，健康历史与手动测试继续可用。恢复配置文件后重新开启插件，自动配置才会重新载入。损坏的运行时间等历史元数据会标记为读取异常，原文件保留用于恢复，不当作健康记录参与清理和统计。

不要同时安装本地版和公开版来运行同一套自动计划。需要从本地目录迁移到公开渠道时，先停用原入口，再安装新入口，并核对保存路径与计划。

## 服务选项与边界

插件服务默认使用 `127.0.0.1:3489`，与 Magpie 网关端口 3425 不同。短暂端口交接会重试；持续占用约 10 秒后显示启动超时，失败后重新开启会再次尝试。端口冲突时，在插件选项设置 `{"port":3491}` 后重新开启。

独立调试需要 Node 22+ 或 Bun：

```sh
node serve.mjs --port 3489 --data-dir .local-data --gateway http://127.0.0.1:3425
```

终端显示访问地址。`MAGPIE_ADDR` 可指定网关，地址需使用 HTTP(S)，不能包含查询参数或片段；可保留网关自身路径前缀和 `/v1`。`MAGPIE_GATEWAY_KEY` 可指定网关 Key；Key 不发送到页面。`bankSource` 插件选项、`MAGPIE_PELICAN_BANK_SOURCE` 环境变量或 `--bank-source` 可指定本地参考库目录，其中应有匹配的 `unified_bank.json` 和 `shared_detector.bin`。

单次生成保留 10 分钟超时和正文、思考合计 4 MiB 的大小保护；提交请求体最大 64 KiB。没有自动重试或自动修复模型输出。独立 iframe 不提供 CPU 硬隔离，异常动画脚本仍可能使界面卡顿。

浏览器打开与保存位置面向本机桌面。远程访问插件时，打开的是服务所在电脑的浏览器或文件夹。
