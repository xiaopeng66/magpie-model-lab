# 模型实验室使用说明 · 1.0.0

## 模型与参数

先选择供应商，再搜索、勾选模型；默认“全部供应商”可跨供应商比较。切换供应商不会清空已经勾选的模型，“清空”一次移除全部选择。思考档位只展示模型目录支持的选项。

手动测试的提示词和高级设置默认折叠。动画每批默认并行 2 个请求，指纹、糖果默认 3 个；不同测试页分别保留编辑值。模型数量没有插件限制，并行数接受正整数。指纹并行按实际采样请求计数，每模型共 3 个样本。

最大输出默认 **64000 Token**。**0 表示不设插件输出上限**：请求中省略输出上限参数，由供应商和网关决定实际限制。它不保证无限输出，也不是费用硬限额。新测试使用默认值；已经保存的自动模型参数保持原值。

指纹选择原生 Messages 接口且上限为 0 时，会预先使用 Magpie 的 Chat 兼容接口，因为原生 Messages 要求正数 `max_tokens`。记录会注明实际接口；不兼容时返回错误，不自动切换重试。

## 结果与用量

三种手动测试共用模型名、供应商、思考／输出用量的布局。排队、生成中、完成、停止、失败和截断分别显示。取消本批次会终止正在执行及排队的请求，已收到的内容继续保留。

接口返回 Token 时直接显示；尚无用量时显示已收到字符数。`—` 表示未知，`0` 表示接口明确报告零。输出 Token 可能已经包含思考 Token，两项不能直接相加。指纹部分样本已返回的用量用 `≥` 表示部分汇总。

### 鹈鹕动画

默认提示词让模型生成鹈鹕骑自行车的 HTML 动画，也可以修改。结果等比缩放到小卡片，长模型名不改变卡片高度。常用按钮包括重播、浏览器打开、源码和详情，播放／停止收在详情中。

重播与浏览器打开读取已保存结果，不重复调用模型。预览链接可跨服务重启使用，删除对应结果后失效。离屏或切页后的动画会卸载预览，返回时重新显示保存文件。

预览允许内联脚本、样式、SVG、Canvas 和 data 图片，限制网络、表单、嵌套框架与对象。模型生成了外部资源依赖或自身布局错误时，动画可能不完整；原始 HTML 保存在结果目录中。浏览器打开按钮使用相同预览限制。

### 模型指纹

同批模型使用相同的 3 个随机数字挑战，每个样本独立请求。卡片直接展示采样数量、进度和首候选；详情中可看原始采样、排名、路由与参考库哈希。也可以从 Magpie 供应商菜单的“检测指纹”进入并预选该供应商。

首次有效检测时下载参考库，之后使用本地快照；点击“更新参考库”才主动更新。更新失败继续保留旧缓存。参考数据默认来自 `lm.ikale.io` 或 `cdn.jsdmirror.com`，不上传你的测试记录；模型请求仍发送到所选供应商。

高级设置可选择严格模式、接口、服务档位和固定供应商账号。“固定供应商账号”用于供应商拥有多个登录账号、需要指定其中一个时；关闭时由 Magpie 自动分配。账号标识只在使用该选项时需要填写。

非严格模式可以对有效的部分样本排名，但不完整证据不显示概率；严格模式要求 3 个完整且未截断的样本。明确路由不一致时不评分。匹配结果只反映参考库覆盖范围内的证据，不能当作模型身份鉴定。

### 糖果测试

使用固定题目提取最终数值答案。21 为绿色，其他明确数值为红色；请求失败、截断、无法明确提取答案时单独标明，避免混为答错。详情保留完整回答与思考。

自动成功率的分母仅包含已有明确数值答案的记录。生成中、排队和待复核不计为失败；数值命中并不证明推理过程正确。

## 自动测试

从手动测试页选好模型后可“加入自动测试”，或在自动测试页“添加模型”。每模型的糖果和动画各有独立计划与开关，共用该模型保存的思考档位和输出上限。自动页不含指纹测试。自动请求共用可配置并行额度，默认 3。

支持指定时刻、固定间隔、工作日、周末、自选星期和时区。新计划默认暂停，开启后从未来时刻开始执行；插件服务需要保持运行。每模型、每种测试、每计划日最多 24 次。

糖果卡一格对应一个计划时刻，24 格正好铺满一行；点击已执行的格子可看详情。动画按模型一行，当天各时刻横向排列，使用滚动条查看。

修改计划时，按模型、测试类型和原定执行分钟复用已有记录；排队延迟不改变匹配时刻，指定时刻与固定间隔互换也可复用。同一时刻已有任务或结果时不新增模型请求。详细的时区、跨午夜、暂停、清理和升级规则见 [自动测试说明](favorites-guide.md)。

## 历史与清理

历史按批次记录，可按类型、来源筛选，列表与预览分别滚动。历史页不能开始新测试。每批提供导出与删除操作；活动批次需结束后才能整批删除。

点击“批量清理”展开选项，按钮变为“关闭”。关闭只收起面板并保留输入。可清除全部，或按本地 `YYYY-MM-DD HH:mm` 清理指定时刻之前的结果；批量清理会保留正在运行与排队的任务。

结果默认保留 7×24 小时，以结束时间计算，没有结束时间的旧记录使用创建时间。服务启动及运行期间每小时检查一次；达到清理条件的结果和生成文件一起删除。自动模型、计划和指纹参考库不随结果清理。

批次 JSON 包含模型、时间、参数、原始输出与已有检测结果，用于留档和离线分析。历史批次导出 → 复制 JSON → 保存为 `.json` 文件即可。当前没有导入恢复功能，导出也不会搬移引用的本机文件。分享前请检查其中的个人内容。

## 保存位置与升级

默认保存于 Magpie 配置目录的 `magpie-pelican-bench/runs`，每条记录独立保存 `run.json`、回复、可用的思考文本、HTML 或采样文件。“保存位置”直接打开文件夹，旁边箭头可展开完整路径。

升级继续使用原来的插件 ID 和目录。替换文件后在 Magpie 中关闭再开启插件，重新打开“模型实验室”，在高级设置底部确认 **1.0.0**。已有计划、已保存参数和历史不会因版本号变化而重置。

不要同时安装本地版和公开版来运行同一套自动计划。需要从本地目录迁移到公开渠道时，先停用原入口，再安装新入口，并核对保存路径与计划。

## 服务选项与边界

插件服务默认使用 `127.0.0.1:3489`，与 Magpie 网关端口 3425 不同。端口冲突时，在插件选项设置 `{"port":3491}` 后重新开启。

独立调试需要 Node 22+ 或 Bun：

```sh
node serve.mjs --port 3489 --data-dir .local-data --gateway http://127.0.0.1:3425
```

终端显示访问地址。`MAGPIE_ADDR` 可指定网关，`MAGPIE_GATEWAY_KEY` 可指定网关 Key；Key 不发送到页面。`bankSource` 插件选项、`MAGPIE_PELICAN_BANK_SOURCE` 环境变量或 `--bank-source` 可指定本地参考库目录，其中应有匹配的 `unified_bank.json` 和 `shared_detector.bin`。

单次生成保留 10 分钟超时和正文、思考合计 4 MiB 的大小保护；提交请求体最大 64 KiB。没有自动重试或自动修复模型输出。独立 iframe 不提供 CPU 硬隔离，异常动画脚本仍可能使界面卡顿。

浏览器打开与保存位置面向本机桌面。远程访问插件时，打开的是服务所在电脑的浏览器或文件夹。
