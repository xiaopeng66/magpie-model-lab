# 模型实验室使用说明 · 1.0.6

## 更新日志

点击标题「模型实验室」旁的「v1.0.6 更新日志」，可查看各版本的更新内容。当前安装版本默认展开，历史版本默认收起；点击版本标题可展开或收起，关闭面板后焦点回到入口。日志随插件打包，可离线阅读。1.0.6 说明只列相对正式 1.0.5 的最终变化；安装、验证和使用说明可从各历史版本的 GitHub 链接查看。

各版本按 GitHub 发行说明整理，提供对应发行页面链接，日期按北京时间显示。

## 模型与参数

首次打开时使用宿主的明暗模式。页面内手动切换主题后，刷新保留所选主题及当前视图。

先选择供应商，再搜索、勾选模型；默认“全部供应商”可跨供应商比较。切换供应商不会清空已经勾选的模型，“清空”一次移除全部选择。思考档位只展示模型目录支持的选项。

勾选模型后，模型卡片下方的整行「账号」按钮会显示当前选择和下拉箭头。点击可选自动分配或多个固定账号；「全选可用账号」一次选中全部可用固定账号，并取消自动分配，明确不可用的账号会跳过。部分选择显示横杠及已选／可选数量；取消全选会清空固定账号，需重新选择账号或自动分配才能确认。读取缓存和提交选择时暂时禁用操作；确认后焦点回到账号按钮。同模型的不同账号各生成一份独立结果，自动分配与固定账号互斥。长名称分两行显示，悬停可查看全文，账号标识和状态分开显示。账号名称仅用于显示，收藏、计划、复测和统计依照稳定模型 ID 与账号 ID 区分；刷新页面不恢复手动账号勾选。提交与真正发出请求前还会再次校验账号。

固定账号不会在失败后自动切换账号。只有网关返回可信且一致的路由证据时才显示「账号已核实」；没有证据时显示未核实，明确不一致时给出异常。账号列表来自宿主缓存，未被标记停用或不可用的账号显示「可选择」；这不代表登录与固定路由已经验证。明确停用、不可用或宿主不支持固定路由的账号不能选择。

手动测试的提示词和高级设置默认折叠。动画每批默认并行 2 个请求，指纹、糖果默认 3 个；不同测试页分别保留编辑值。模型数量没有插件限制，并行数接受非负整数，**0 表示不设插件并行上限**。指纹并行按实际采样请求计数，每模型共 3 个样本。

三种手动测试分别记忆合法参数，页面刷新和服务重启后恢复，包括生成超时及支持的思考档位。勾选模型和固定账号不记忆，已保存的自动模型参数保持独立。连续编辑在 600 ms 后合并保存，生成始终采用点击时的完整参数副本，排队期间再修改输入或来源预设不会改变任务。

参数保存超过 5 秒未确认会提示等待；10 秒后停止本次客户端等待，再做最多 5 秒对账。网络异常或同组冲突会保留草稿，重试先核对服务端状态；同组冲突可在「本地设置」明确选择本地草稿或服务器参数。关闭浏览器时只做尽力保存，请以「参数已保存到本地」反馈为准。

高级设置中的「常用参数 → 添加 / 编辑方案」直接编辑方案名称、生成超时、输出上限和每批并行数。新建方案使用当前测试类型的默认值；选择已有方案后，直接修改其名称与参数，再点击「保存修改」。动画方案还可编辑提示词，指纹方案还可编辑请求接口、服务档位和严格采样；「模型思考档位」可添加、修改和移除指定模型的档位，不会勾选测试模型或账号。保存方案不会改动主界面；点击「应用到测试」或在主界面的方案列表选择已保存方案才会载入，载入后可继续调整。未保存的修改会禁用应用，切换方案时会提示是否放弃草稿。

方案名称去空白后为 1–40 字，同一模式不能重名，总计最多 50 个、设置文件最多 1 MiB。方案不包含模型勾选、固定账号、重复轮数、自动计划或凭据；删除方案保留主界面输入与已有任务。主界面参数无效时仍可独立编辑方案；保存或读取失败会保留弹窗输入，其他页面修改或删除同一方案时，会要求重新选择核对后再保存。

页面右上角、主题按钮旁的「本地设置」按「运行提醒」「请求控制」「每日用量」「配置迁移」分类。分类导航固定在内容区上方，长表单独立滚动，字段不会被标签遮挡。切换分类保留未保存的表单输入并回到该分类顶部，可用方向键、Home 和 End 切换。历史保留时间在「历史记录」页设置。

最大输出默认 **64000 Token**。**0 表示不设插件输出上限**：请求中省略输出上限参数，由供应商和网关决定实际限制。它不保证无限输出，也不是费用硬限额。新测试使用默认值；已经保存的自动模型参数保持原值。

生成超时位于高级设置的 Token 输出上限下方，默认 **600 秒**，接受 0–2147483.647 秒，精度最多三位小数，例如 1.001 秒保存为 1001 毫秒。**0 表示不设插件侧超时**，仍可手动取消；供应商或网关自身的超时仍可能提前结束请求。动画、糖果按每个生成请求计时，指纹按每个采样请求计时，排队等待不计入。自动模型与计划保存该参数，原条件复测使用原记录的超时；旧记录缺少该值时按 600 秒处理。

指纹选择原生 Messages 接口且上限为 0 时，会预先使用 Magpie 的 Chat 兼容接口，因为原生 Messages 要求正数 `max_tokens`。记录会注明实际接口；不兼容时返回错误，不自动切换重试。

### 重复测试

高级设置的「重复测试」接受可精确表示的正整数，默认为 1，不设固定轮数上限，31、100 等次数都可提交。糖果测试只保留答案为 21 的原糖果题，展开「糖果题面」可查看题目。基础推理三题、题目选择及随机题序入口已移除。已有三题历史仍可查看和保存批次 JSON，但不能新建或原条件复测。

点击开始前显示结果份数和生成请求上界，指纹每份结果对应 3 次采样请求。例如 1 个模型、2 个固定账号、2 轮会生成 4 份原糖果题结果；卡片显示重复轮次。每个模型／账号组合另起一行，同一组合的第 1、2、3…轮连续排列；当前、最近批次和手动历史采用相同展示方式。后端执行顺序仍按轮次和目标交错展开。

提交时冻结原糖果题面、标准答案和判分器版本；标准答案仅在本地判分，不发送给模型。无法明确提取最终数值时显示待复核。准备条目期间累计检查请求与元数据，合计超过 8 MiB 时，在任何记录保存和模型请求之前整批拒绝；输入数量超出可精确计算的范围也会提示调整，已有任务和历史保持可用。

详情中的「本组重复统计」按同账号目标、同题目分组，区分提交、实际执行、完成、可判分、命中、失败和取消。命中率分别使用可判分样本及实际执行样本作为分母；零分母显示无样本。P90 耗时至少需要 10 个有效样本。原条件复测对每条所选来源记录仅运行一次，不再次乘上原实验轮数；自动计划仍为每时刻一次原题。

## 结果与用量

三种手动测试共用模型名、供应商、思考／输出用量的布局。排队、生成中、完成、停止、失败和截断分别显示。取消本批次会终止正在执行及排队的请求，已收到的内容继续保留。

所有结果通过「查看详情」打开原详情侧栏。生成期间显示简短的阶段、已用时间和剩余超时，指纹三个采样各占一行；结束后隐藏这部分提示，耗时与用量仍在原统计区域查看。排队不消耗生成超时，未同步时不猜计时。详情头部的复制按钮旁提供独立的「保护此记录／解除记录保护」按钮，按下状态表示已保护。只收到心跳、ping 或原始网络字节不算有效模型数据。

连续 120 秒没有有效模型数据会显示提醒，请求仍继续运行，总生成超时仍按原参数执行。在「本地设置 → 运行提醒」可关闭提醒；它不会自动取消、重试或重新发送模型请求。计时按单调时钟推进，断线／重连及迟到快照不回退进度；旧记录没有进度字段时仍可查看原始结果。

本批结果下方按相同模型顺序显示最近 **5 个已结束的历史批次**。结果区最底部的「前往历史记录」会打开历史页，自动筛选当前测试类型和「手动测试」，从最新记录开始查看；历史不足 5 批时显示已有批次。

接口返回 Token 时直接显示；尚无用量时显示已收到字符数。`—` 表示未知，`0` 表示接口明确报告零。输出 Token 可能已经包含思考 Token，两项不能直接相加。指纹部分样本已返回的用量用 `≥` 表示部分汇总。

### 鹈鹕动画

默认提示词让模型生成鹈鹕骑自行车的 HTML 动画，也可以修改。结果等比缩放到小卡片，长模型名不改变卡片高度。「查看详情」打开右侧抽屉，可切换动画预览、HTML 源码与原始输出，也可停止／播放预览。

重播与浏览器打开读取已保存结果，不重复调用模型。预览链接可跨服务重启使用，删除对应结果后失效。离屏或切页后的动画会卸载预览，返回时重新显示保存文件。

预览允许内联脚本、样式、SVG、Canvas 和 data 图片，限制网络、表单、嵌套框架与对象。模型生成了外部资源依赖或自身布局错误时，动画可能不完整；原始 HTML 保存在结果目录中。浏览器打开按钮使用相同预览限制。

### 模型指纹

同批模型使用相同的 3 个随机数字挑战，每个样本独立请求。卡片直接展示采样数量、进度和首候选，省略的候选名称和参考模型家族可悬停查看全文；详情中可看原始采样、排名、路由与参考库哈希。也可以从 Magpie 供应商菜单的“检测指纹”进入并预选该供应商。

首次有效检测时下载参考库，之后使用本地快照；点击“更新参考库”才主动更新。更新失败继续保留旧缓存。参考数据默认来自 `lm.ikale.io` 或 `cdn.jsdmirror.com`，不上传你的测试记录；模型请求仍发送到所选供应商。

高级设置可选择严格模式、接口和服务档位。指纹与其他手动测试共用模型卡片下方的「账号」入口，可由 Magpie 自动分配或选择多个固定账号；每个固定账号得到独立的三采样结果，不再在高级设置里单独填写账号标识。

非严格模式可以对有效的部分样本排名，但不完整证据不显示概率；严格模式要求 3 个完整且未截断的样本。明确路由不一致时不评分。匹配结果只反映参考库覆盖范围内的证据，不能当作模型身份鉴定。

### 糖果测试

原糖果题提取最终数值答案，21 为绿色，其他明确数值为红色；多轮测试的结果卡显示轮次。请求失败、截断、无法明确提取答案时单独标明，避免混为答错。详情保留完整回答与思考。

自动成功率的分母仅包含已有明确数值答案的记录。生成中、排队和待复核不计为失败；数值命中并不证明推理过程正确。

### 原因说明与近期趋势

异常卡片和详情会区分生成超时、请求限流、认证／权限错误、响应中断、保存失败、输出截断、无效输出、指纹无法评分及糖果答案不匹配等原因，并给出相应建议。无法确定具体原因时保留「请求失败」，原始错误仍可查看。结果读取失败应先重试读取；动画当前预览的运行错误与模型生成状态分别显示，查看源码或暂停预览不会清掉刚观察到的错误。

三种结果详情均提供默认收起的「同模型近期趋势」。只统计当前保留历史中最近 **20 条同模型、同题面、同完整参数的已结束记录**，不包含进行中和已取消的记录。糖果显示答案命中率，分母为可明确判定的答案，包含不匹配答案；动画显示生成完成率，完成不代表预览运行正确；指纹显示可评分率及最近候选分布，只有同一组原题与同一参考库的记录才会合并。

耗时和总 Token 使用可判定／可评分／已生成结果的中位数，标为部分汇总的总 Token 不参与精确中位数；少于 3 条可用结果时显示样本不足。异常数量包括已明确判定为不匹配的糖果答案，因此与可判定数量并非互斥。展开后可滚动查看记录表；色条从早到晚排列，点击跳到原历史记录并自动筛选其测试类型与来源。旧记录原条件不完整时暂不汇总趋势。

趋势按完整条件和账号目标区分。相同条件连续 3 次认证、限流或生成超时会在详情显示提示；取消、未执行、重启、保存或连接故障不计入该规则。近期变慢需要最近 5 条有效耗时的中位数超过此前 10 条的 2 倍，并且至少增加 30 秒；历史不足不显示。提示保留依据记录，不自动停用账号或计划。

### 请求控制与每日用量

「本地设置 → 请求控制」用于跨批次请求限制。测试设置中的并行数只管当前一批；这里按每个供应商／固定账号计算，同时限制本插件的所有手动批次和自动计划。例如本批并行数为 4、供应商上限为 2，该供应商同时最多执行 2 个请求，其余等待空位；不同供应商分别计算。固定账号上限只作用于明确选定的账号。最小请求间隔限制相邻请求的启动时间，适合接口有频率限制时使用；0 表示不额外限制对应项目。

默认限制点击「保存默认限制」生效。已保存的供应商／账号规则直接显示在列表中，每条提供「编辑规则」「删除规则」。点击「新增供应商规则」或「新增账号规则」，直接在编辑器填写参数，再点击「保存规则」生效，不需要再保存整组。规则替代对应对象的默认限制，显式 0 可取消该项限制；删除规则恢复默认值。默认输入与单条规则分开保存，保存单条规则不会提交尚未保存的默认输入。

规则列表优先于默认设置展示。请求间隔以秒填写，最多三位小数，如 1.001 秒；长规则名称最多显示两行，悬停可查看完整名称，编辑与删除操作独立排列。

打开请求控制时自动显示当前等待，亦可点击「刷新等待状态」。显示实际模型、账号、等待原因和恢复时间。收到 HTTP 429 时插件暂缓同一目标的新请求，其他可执行目标继续运行；失败请求不会自动重试。恢复时间到达后继续准入，不提供手动绕过限流等待的入口。

规则保存会核对该对象是否被其他页面修改，冲突时保留输入；无关对象的规则更新会合并。保存期间禁用重复提交，关闭面板后的迟到读取不提交设置。新账号规则切换供应商时先清空账号，缓存读取失败、账号明确不可用或宿主不支持固定路由时不能保存该账号选择。已保存规则仍可按原身份编辑或删除。

「本地设置 → 每日用量」打开即显示本机日期和时区、今日请求、已知 Token、未返回 Token 的请求数，以及各供应商／固定账号明细。自动分配单独列出。大数字用千位分隔符，名称可换行；小窗口会调整统计卡和明细列。可点击「刷新今日用量」，读取失败保留上次统计并提供重试。

按本插件实际发起的物理请求计数，指纹每次采样单独计入。待发送的请求不计数；没有请求时 Token 明确为 0，已发出但接口未提供完整用量时显示「未返回」，部分已知 Token 只合计已返回的值。首日或缺少部分时段时明确标注覆盖范围。统计不包含 Magpie 其他页面或其他软件的请求，也不推算费用。

每日用量只作统计，没有每日额度设置或拦截。删除历史不会减少请求数和 Token；已发出后取消的请求仍计入。旧设置和配置 JSON 中的额度字段在读取或导入时移除，不会重新启用限制。用量账本沿用原数据位置，升级继续保留既有统计。

请求发送前持久记录，并重查取消和计划期限；明确未发出的请求释放记录。发起窗口异常退出而无法确定是否发出的请求保守记录并显示说明。当前生成不因请求控制修改而中断。账本详细记录保留 72 小时，较早记录压缩为摘要；账本或冷却状态不可安全写入时暂停新请求，以保护既有数据。

### 配置导入与分享

「本地设置 → 配置迁移」使用专用 `model-lab-config-v1` JSON，最大 2 MiB。配置包含手动参数、常用参数方案、历史保留、运行提醒和请求控制，以及收藏目标和计划；不包含宿主凭据、历史回答、用量账本或调度 claims。分享模式默认去除账号绑定及账号专属的请求控制规则，导入方必须重新选择账号或自动分配。

从本地文件导入后，分别选择本地设置、目标参数和计划的保留／覆盖／跳过方式，再预览完整候选。缺少绑定、目标重复、模型或账号不可用时不能确认应用。选择变化、配置 revision 变化或超过 5 分钟后需重新预览；缩短保留策略还须确认固定时点的清理影响。

应用导入需要等待生成、已接受配置写入和保存窗口结束。受影响或新计划保持暂停，核对后手动启用，只执行未来时格；未涉及计划保持原状态。本地原 ID 和 claims 保留。导入使用持久 prepared／committed 日志，重启先恢复事务；遇到无法识别的外部文件摘要时保留现场并暂停配置写入及自动调度。

## 自动测试

从手动测试页选好模型／账号目标后可“加入自动测试”，或在自动测试页“添加模型”。每个账号目标的糖果和动画各有独立计划与开关，共用该目标保存的思考档位和输出上限。管理模型可将另一账号添加为新目标，不能原地改写既有目标身份。自动页不含指纹测试。自动请求共用可配置并行上限，默认 3；管理模型页直接显示并行输入，0 表示不设插件并行上限。

账号选择面板读取缓存时会显示读取反馈，并暂时禁用确认和刷新。缓存未标记停用或不可用的账号显示「可选择」，即使宿主未提供启用标志也可选择；这不等于认证成功，实际认证和路由在请求结果中核实。明确不可用的账号仍禁用。取消选择会保留原目标。模型参数与计划面板中的长目标名称最多显示两行，悬停标题可查看完整名称和模型标识。

支持指定时刻、固定间隔、工作日、周末、自选星期和时区。新计划默认暂停，开启后从未来时刻开始执行；插件服务需要保持运行。每模型、每种测试、每计划日最多 24 次。

糖果卡一格对应一个计划时刻，24 格正好铺满一行；点击已执行的格子可看详情。动画按模型一行，当天各时刻从新到旧横向排列。默认把当前时间之前最近的计划时刻放在可见区域左侧，成功、失败、取消、中断、截断、排队和空结果均按同一规则选择，不会跳回更早的成功结果。到达新时刻或该时刻出现任务时自动跟随；可手动滚动，普通用量与计划状态更新保留位置。刷新页面或从其他测试页返回长廊时重新定位。当天尚无已到达时刻时，显示第一个即将到来的时刻。

同类卡片保持等高，缺少结果或用量时预留对应位置。详情中的长内容显示细滚动条，头部与关闭按钮保持可见；JSON 和参数输入框也可单独滚动。

修改计划时，按模型、测试类型和原定执行分钟复用已有记录；排队延迟不改变匹配时刻，指定时刻与固定间隔互换也可复用。同一时刻已有任务或结果时不新增模型请求。详细的时区、跨午夜、暂停、清理和升级规则见 [自动测试说明](favorites-guide.md)。

## 历史与清理

手动测试按提交批次记录；自动测试按本地日期和类型分组，同日同类且原定时间点一致的模型并排显示。可按类型、来源筛选，再次点所选条目可收起预览。每批提供导出操作，在批量清理面板打开时可删除单批；活动批次需结束后才能整批删除。

历史动画每日长廊每个模型一行，最新在左、最早在右。「最新」「最早」会一次同步跳到当前所选每日批次各模型行的最左或最右，不跨日期；到达对应端点后按钮禁用。自动测试页仍保留较早、当前和较新时段的原有导航。

三种手动测试的本批次、最近五个历史批次，以及历史页的手动批次，在标题行右侧提供「原条件复测」。历史批次标题与按钮保持对齐，窄窗口中的时间和数量显示在下一行。

「原条件复测」可从同一手动批次中选择多条记录，也可在单条详情中点击「复测此条」。自动历史需先选模型和时刻，再从该条详情复测，一次仅运行一条。核对页的参数只读，支持选择全部可复测记录、仅选异常，或按当前出现的超时、限流、截断、答案不匹配等原因选择；失败、中断、截断、无效输出、糖果待复核及明确答错均属于异常。只有该类别中具备完整原条件的记录会被选中，不能复测的记录保留禁用说明。默认排除已取消记录，正在测试的记录不可复测；选择分类本身不会发送生成请求。

复测使用保存的原模型、题面、思考档位、输出上限和并行数；指纹另保留原三组挑战、实际接口、采样设置、固定账号及参考库快照。缺少原条件、原模型或原参考库时会禁用并显示原因。提交后创建新的手动批次，保留原记录、自动计划和侧栏未提交的参数草稿；来源说明可跳回原历史记录并定位原模型和原时刻，原记录清理后会显示提示。

点击“批量清理”展开选项，按钮变为“关闭”。关闭只收起面板并保留输入。可清除全部，或按本地 `YYYY-MM-DD HH:mm` 清理指定时刻之前的结果；批量清理会保留正在运行与排队的任务。

每条详情均可「保护此记录」或「解除记录保护」。自动保留清理、全部清理、指定时间、单批及每日组清理都跳过受保护记录；反馈分别显示删除、活动跳过、保护跳过和失败数量。保护状态独立于原始回答与自动模型收藏。

结果默认保留 7×24 小时，以结束时间计算，没有结束时间的旧记录使用创建时间。服务启动及运行期间每小时检查一次；达到清理条件的结果和生成文件一起删除。自动模型、计划和指纹参考库不随结果清理。

「历史记录」页的「保留 7 天」按钮可选 7/30/90 天、自定义整数 1–36500 天或永久保留，按钮随当前设置更新，0 不表示永久。预览显示当前到期候选、活动／保护跳过，以及元数据大小和实测文件大小；统计未完成时明确标注。缩短策略须用 5 分钟内有效预览确认，保护或设置变化后要重新预览。保存策略不会立即删除文件，下一清理周期重新按实际时间计算；永久保留仍允许手动清理，保护规则继续生效。

历史列表常驻摘要，原始回答、思考、HTML 和采样正文在打开详情、预览或导出时按需读取。损坏记录单独跳过，原文件保留供恢复，不会阻断健康历史列表。

详情可显式保存最多 2000 字备注及 10 个标签，每个标签最多 20 字。保存采用单条记录 revision，冲突时保留草稿并禁用保存；点击「读取当前注释并保留草稿」核对当前版本后可再次保存，解除记录保护不删除备注和标签。历史搜索框有独立标签、搜索图标及下方范围说明，可检索模型、账号、备注和标签；「更多筛选」还可筛选日期、类型、结果和保护状态，筛选不读取原始正文。应用条件后入口显示「筛选中 · 条件数」，关闭面板仍显示生效状态，清除条件后恢复「更多筛选」。历史筛选栏按「全部测试、全部来源、更多筛选、保留时间」排列；筛选和保留时间分别打开独立面板。

批次 JSON 包含模型、时间、参数、原始输出与已有检测结果，用于留档和离线分析。点击历史批次的导出图标，在右侧抽屉查看内容，选择「复制 JSON」或「下载 JSON」。「下载 JSON」打开系统另存为窗口，选择文件夹和文件名，成功后显示实际保存路径；取消不生成文件，失败后可重试。保存窗口未关闭时不能重复打开另一个；批次仍在运行时需等待结束后保存。读取失败可重试；关闭抽屉后列表仍停在原处。批次 JSON 用于留档和分析，不搬移引用的本机文件。分享前请检查其中的个人内容。

单次批次导出与 JSON 保存使用 **16 MiB 预算**，按保存记录大小预检并核验实际序列化内容；同时只处理一个批次导出。超限会明确提示，历史详情和原始文件仍保留。大型批次可从「保存位置」取得每条记录的原始文件；后续测试可减少单批模型数量，分批留档。

## 保存位置与升级

默认保存于 Magpie 配置目录的 `magpie-pelican-bench/runs`，每条记录独立保存 `run.json`、回复、可用的思考文本、HTML 或采样文件。“保存位置”直接打开文件夹，旁边箭头可展开完整路径。

升级继续使用原来的插件 ID 和数据目录。先停止目标插件再替换文件，开启后重新打开“模型实验室”，在高级设置底部确认 **1.0.6**。已有计划、已保存参数和历史继续沿用；本地替换前应完整备份数据目录。1.0.6 本次未上传 GitHub。

新增 `.settings/state.json` 与 `.annotations/state.json`，各自保留 `state.previous.json`；B–D 还使用 `.queue/state.json`、`.budgets/state.json` 和 `.imports/journal.json`。`.budgets` 仅为保留既有用量而沿用的目录名，当前已没有每日额度功能。设置／注释文件损坏、未知格式、已存在私有目录内文件丢失，或写入时发现文件被服务外替换，会保留现场并暂停危险清理，设置／保护暂时只读。队列或用量账本故障另暂停新请求；配置事务无法安全恢复时暂停配置写入和自动调度，健康历史仍可阅读。

离线恢复时先停用插件、核实后台端口已释放并完整备份原数据，再检查当前文件与上次有效副本。设置恢复时先在经校验的候选中设为永久保留，再恢复原目录；保护索引无法证明完整时继续保持清理暂停。不要通过删除私有设置／保护目录让程序把丢失状态当作首次安装。

同一数据目录只能有一个新版本写者。正常 Magpie 宿主连接关闭时，服务先中断生成、排空已接受写入，再释放 `.data-owner`。异常退出残留不会自动按 PID 或时间抢占；离线核实无写者并备份后，仅处理残留 `.data-owner`，保留运行记录及设置文件。

降级到 1.0.5 会忽略记录保护和自定义／永久保留，恢复旧的 7 天清理。不能直接用旧版启动升级后的原数据目录；须停服、保留完整备份并在隔离副本核验数据兼容。`tools/replace-local.ps1` 的 `-KeepDisabledOnRollback` 可在替换失败后保持停用，待数据核验后再恢复。

收藏配置损坏时，服务保留原配置文件并停用自动调度；页面显示恢复说明，收藏和计划暂时只读，健康历史与手动测试继续可用。恢复配置文件后重新开启插件，自动配置才会重新载入。损坏的运行时间等历史元数据会标记为读取异常，原文件保留用于恢复，不当作健康记录参与清理和统计。

不要同时安装本地版和公开版来运行同一套自动计划。需要从本地目录迁移到公开渠道时，先停用原入口，再安装新入口，并核对保存路径与计划。

## 服务选项与边界

插件服务默认使用 `127.0.0.1:3489`，与 Magpie 网关端口 3425 不同。短暂端口交接会重试；持续占用约 10 秒后显示启动超时，失败后重新开启会再次尝试。端口冲突时，在插件选项设置 `{"port":3491}` 后重新开启。

独立调试需要 Node 22+ 或 Bun：

```sh
node serve.mjs --port 3489 --data-dir .local-data --gateway http://127.0.0.1:3425
```

终端显示访问地址。`MAGPIE_ADDR` 可指定网关，地址需使用 HTTP(S)，不能包含查询参数或片段；可保留网关自身路径前缀和 `/v1`。`MAGPIE_GATEWAY_KEY` 可指定网关 Key；Key 不发送到页面。`bankSource` 插件选项、`MAGPIE_PELICAN_BANK_SOURCE` 环境变量或 `--bank-source` 可指定本地参考库目录，其中应有匹配的 `unified_bank.json` 和 `shared_detector.bin`。

单次生成默认 600 秒超时，可在高级设置修改或填 0 关闭插件侧超时；正文、思考合计仍有 4 MiB 的大小保护；提交请求体最大 64 KiB。没有自动重试或自动修复模型输出。独立 iframe 不提供 CPU 硬隔离，异常动画脚本仍可能使界面卡顿。

浏览器打开与保存位置面向本机桌面。远程访问插件时，打开的是服务所在电脑的浏览器或文件夹。
